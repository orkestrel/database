# Native-first campaign folder

Read in this order:
1. `plan.md`: the goal, the exit criterion, § State, and § Sequence.
2. `designs/native.md`: the ruled design, with its units and releases in § 8.
3. `research/intake.md`: the requests and measurements that opened the campaign, verbatim.
4. `research/audit.md`: the capability audit the design rules on, cited against database 0.0.23, sqlite 0.0.18, indexeddb 0.0.18, and relation 0.0.21.

`ledger.md` holds one row per dispatched unit and per user ruling.

Ids: a unit is named by its row in `designs/native.md` § 8, such as "Paging wave, Core". A design addendum is a section appended to `designs/native.md`.
